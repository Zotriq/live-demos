# Importing contacts from CSV

- Maximum file size is 50 MB or 200,000 rows.
- The first row must contain column headers. Required column: email.
- Files must be UTF-8 encoded. Excel exports in other encodings show garbled characters such as "Ã©".
  Fix: in Excel choose "Save As → CSV UTF-8".
- Imports run in the background; you get an email when they finish.
