# Two-factor authentication (2FA)

- Turn on 2FA in Profile → Security. We support authenticator apps and security keys.
- Lost your phone? Sign in with one of the 10 backup codes you saved when you set up 2FA.
- No backup codes: a workspace admin can reset 2FA for you in Settings → Members → ⋯ → Reset 2FA.
- For security, support staff cannot turn off 2FA on an account. Only a workspace admin can.
